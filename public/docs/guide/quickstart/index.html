GUIDE / QUICKSTART

快速开始

用几分钟启动 CHARACTOID 展示站，并了解如何把它作为角色 Agent 产品原型继续开发。

安装与运行

需要 Node.js 18 或更高版本。

git clone git@github.com:TKGEKKOU/charactoid-product-site.git
cd charactoid-product-site
npm install
npm run dev

启动后访问 http://127.0.0.1:18080/。

项目结构

  • src/main.js：页面结构、交互和安装命令切换。
  • src/style.css：官网视觉系统、响应式布局和动效。
  • public/assets：Logo、音频、Live2D 等静态素材。
  • public/docs：本开发者文档，可直接随站点发布。

部署到 GitHub Pages

执行生产构建后，将 dist 目录发布到 GitHub Pages。仓库已经准备好对应的静态入口，后续可以接入 GitHub Actions 自动部署。

npm run build
